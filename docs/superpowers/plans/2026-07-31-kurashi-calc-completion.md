# くらし算 初期公開完成計画

**Goal:** トップLPを、4つの実用計算ツール、記事、検索、法務ページを備えた広告掲載可能な静的Webメディアへ完成させる。

## Global Constraints
- Cloudflare Workers Static Assetsで配信する。
- 入力値はブラウザ内だけで処理し保存しない。
- 計算式・初期値・公的参照元を各ツールに表示する。
- 広告枠を入力フォームや主要操作と隣接させない。
- 360px幅から利用可能にする。
- 外部ライブラリへ依存しない。

5. 根拠付き記事4本を実装する。
6. 運営者・問い合わせ・利用規約・プライバシーポリシーを実装する。

8. 全テスト、リンク検査、JavaScript構文、PC/スマホ表示を検証する。
