# くらし算 トップLP デザイン仕様

## 目的

一般ユーザーが「暮らしに必要な量と費用」をすぐ計算できることを伝え、計算ツール利用・回遊・広告収益につなげる。

## 承認済みデザイン

2026-07-31に承認されたモックアップを基準とする。薄いアイボリー背景、深緑のブランドカラー、オレンジの主要CTA、白い角丸カード、線画イラストを使用する。

## 初回実装範囲

- 固定ヘッダーとスマートフォン用メニュー
- ヒーローコピーとCTA
- 実際に動作する家族のお米計算
- 人気計算ツール4件
- 広告用プレースホルダー2枠
- 目的別カテゴリ7件
- 3ステップの使い方
- 信頼性訴求4件
- 記事カード4件
- フッター
- レスポンシブ対応
- SEO基本設定、robots.txt、sitemap.xml、OG画像プレースホルダー
- Cloudflare Workers Static Assets用設定

## 対象外

- AdSenseの本番広告コード
- 記事詳細ページ
- お米以外の計算ロジック
- 会員登録、履歴保存、データベース
- 管理画面

## お米計算仕様

- 大人: 1人1食あたり生米100g
- 子ども: 1人1食あたり生米80g
- 必要量kg = `(大人人数 × 100 + 子ども人数 × 80) × 食事回数 × 日数 ÷ 1000`
- 5kg袋数は必要量を5で割って切り上げる
- 概算費用は1kgあたり900円で計算する
- 人数は0〜12人、食事回数は1〜3回、期間は7・14・30・60・90日
- 初期値は大人2人、子ども2人、30日、2回

## 品質条件

- 360px幅から崩れず利用できる
- 計算フォームはキーボード操作できる
- 主CTAと広告を隣接させない
- JavaScript無効時にもLP本文を読める
- 外部フォント・外部画像に依存しない
- Lighthouseを意識し、画像はSVG、JavaScriptは最小限にする
